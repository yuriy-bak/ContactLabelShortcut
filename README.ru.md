# Contact Label Shortcut

Приложение для Android, которое ставит на рабочий стол ярлык метки контактов: одно нажатие открывает все контакты с этой меткой. Работает без интернета.

## Как это работает

- При добавлении ярлыка приложение показывает метки контактов (метки Google Контактов и группы других аккаунтов), вы выбираете одну.
- Ярлык открывает метку там, где указано в настройке на главном экране приложения: системный выбор (приложение контактов по умолчанию, `ACTION_VIEW` на `content://com.android.contacts/groups/<id>`; Google Контакты это поддерживают), конкретное приложение или собственный список.
- Собственный список открывается практически мгновенно. У каждого контакта аватарка и кнопки: звонок (открывает номеронабиратель), SMS и чаты в мессенджерах, которые есть у контакта на этом телефоне (WhatsApp, Telegram, Signal, Viber, Threema). Остальные действия других приложений — в меню ⋮. Нажатие на имя открывает контакт в любом приложении контактов. Долгое нажатие на звонок или SMS — выбор номера.
- Ярлык хранит серверный id и название метки, поэтому продолжает работать после пересинхронизации аккаунта, когда меняется локальный id.
- Единственное разрешение — чтение контактов. Приложение не обращается к сети.

## Установка

Скачайте APK со страницы [Releases](https://github.com/yuriy-bak/ContactLabelShortcut/releases) и установите. Нужен Android 8.0 или новее. Чтобы получать обновления автоматически, добавьте репозиторий в [Obtainium](https://github.com/ImranR98/Obtainium).

## Использование

- **Из лаунчера:** долгое нажатие на рабочем столе → Виджеты → Contact Label Shortcut → перетащите **Метка контактов** на экран → выберите метку.
- **Из приложения:** откройте Contact Label Shortcut → **Создать ярлык** → выберите метку → подтвердите добавление.

## Сборка

APK собирает GitHub Actions (lint, юнит-тесты, release-сборка): каждый push в `main` загружает артефакт, а тег `v*` публикует релиз с APK. Тег должен быть `v` + `versionName` из `app/build.gradle.kts`; перед каждым релизом там поднимаются `versionCode` и `versionName`.

Локальная сборка (JDK 17, Android SDK):

```bash
./gradlew :app:assembleRelease
```

Без релизного ключа APK подписывается локальным debug-ключом. Релизы подписываются в CI ключом из GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`); в репозитории его нет.

До 0.1.0-beta.20 релизы подписывались открытым тестовым ключом. Начиная с 0.1.0-beta.21 подпись новая: перед установкой один раз удалите старую бету.
